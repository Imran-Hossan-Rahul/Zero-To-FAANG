## 👋 What Is This?

This is not a tutorial. Not a curated list of "top 10 resources." Not another generic roadmap copy-pasted from the internet.

This is my **actual preparation journey** — structured, tracked, and logged honestly from day one. Every skill in this repository was chosen because it genuinely matters for landing a software engineering role at companies like Google, Meta, Amazon, Apple, and Microsoft.

If you are a CS student or self-taught developer seriously working toward the same goal, feel free to fork this, follow along, or use the tracker for yourself.

## 🗺️ The Roadmap

7 phases. Roughly 14+ months. No skipping.

| Phase       | Focus                                                                                  | Timeline    |
| ----------- | -------------------------------------------------------------------------------------- | ----------- |
| **Phase 1** | Core CS: OS, Networks, DBMS, Big O + C/C++, Python, Java, Git, Linux                   | Month 1–2   |
| **Phase 2** | Full DSA: every data structure + algorithm + LeetCode Easy 100+ + Codeforces Pupil     | Month 3–5   |
| **Phase 3** | LeetCode Medium 150+ + Codeforces Specialist + DP deep dive + AtCoder ABC/ARC          | Month 6–7   |
| **Phase 4** | Full Stack: JS, TypeScript, React, Node.js, REST, gRPC + SQL, MongoDB, Redis, Kafka    | Month 8–9   |
| **Phase 5** | System Design: scaling, CAP, sharding, distributed systems + design 8–10 real systems  | Month 10–11 |
| **Phase 6** | LeetCode Hard 50+ + Mock coding interviews + Mock system design + AtCoder ARC          | Month 12–13 |
| **Phase 7** | Portfolio projects + Resume + LinkedIn + Referrals + Behavioral (STAR) + Communication | Month 14+   |

## 🧠 The Tracker

The `SWE_Learning_Tracker.xlsx` file is the core of this repo. It tracks every single skill with:

| Column             | What It Contains                                     |
| ------------------ | ---------------------------------------------------- |
| **Skill / Topic**  | Exactly what needs to be learned                     |
| **Category**       | Which area it belongs to                             |
| **Key Concepts**   | What to focus on — concise, no fluff                 |
| **Status**         | `⬜ Not Started` · `🔄 In Progress` · `✅ Completed` |
| **Date Completed** | Logged when finished                                 |
| **My Notes**       | Personal resources, links, and tips                  |

A **Dashboard sheet** shows overall progress as a percentage per category with a visual status bar that auto-calculates.

## 📚 Core Resources

**DSA & Competitive Programming**

- [LeetCode](https://leetcode.com) — primary interview coding platform
- [Codeforces](https://codeforces.com) — CP grind, targeting Specialist (1400+)
- [AtCoder](https://atcoder.jp) — clean problems, excellent for DP and math

**System Design**

- [System Design Primer](https://github.com/donnemartin/system-design-primer)
- _Designing Data-Intensive Applications_ — Martin Kleppmann

**CS Fundamentals**

- [CS50 by Harvard](https://cs50.harvard.edu)
- [MIT OpenCourseWare](https://ocw.mit.edu)

**Books**

- _Clean Code_ — Robert C. Martin
- _The Algorithm Design Manual_ — Steven Skiena
