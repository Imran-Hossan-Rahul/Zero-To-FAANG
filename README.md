# Zero-To-FAANG 🚀

Welcome to the **Zero-To-FAANG** repository! This is my personal coding and learning tracker as I prepare for Software Engineering roles at top-tier tech companies.

## 📌 About This Repository

This repository documents my daily problem-solving journey, focusing on mastering Data Structures and Algorithms (DSA). By committing code daily, I am building consistency, improving my problem-solving skills, and preparing for rigorous technical interviews.

## 📂 Repository Structure

The repository is organized chronologically by days. Inside each folder, you will find my solutions to various algorithmic problems:

- **`Day XX/`**: Contains solutions for problems solved on a specific day (e.g., LeetCode, CodeChef).
- **`SWE_Learning_Tracker_Upgraded (1).xlsx`**: My personal progress tracker detailing the topics covered, questions solved, and my revision schedule.

## 🛠️ Languages & Tools

- **Primary Language:** C++
- **Platforms:** LeetCode, CodeChef

Feel free to browse through the daily folders. Each file is typically named after the problem it solves (e.g., `leetcode 1281.cpp`). The code includes my approach to solving these algorithmic challenges.
